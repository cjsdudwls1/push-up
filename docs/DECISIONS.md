## 기술·운영

| | |
|---|---|
| 앱 ID | `io.github.cjsdudwls1.pushuprpg` |
| 크래시·분석 | Firebase Crashlytics + Analytics |
| 고냥이 모드 위치 | 온보딩 튜토리얼. 천장을 밀어올리는 동작이 말 없이 깊이를 가르칩니다 |

앱 ID는 프로덕션 출시 후 영원히 바꿀 수 없습니다. 코드 패키지(`namespace`)는
`com.pushuprpg.app` 그대로 두었습니다 — 둘은 원래 별개이고, 37개 파일을 일괄 리네임하는 것은
이 환경에서 컴파일로 검증할 수 없는 종류의 변경이라 위험 대비 이득이 없습니다. 원하면
Android Studio의 리팩터링으로 언제든 맞출 수 있습니다.

Crashlytics를 넣기로 한 이상 개인정보처리방침과 Play Data Safety 신고에 반영해야 합니다.
"영상은 어디로도 전송되지 않는다"는 여전히 사실이고 그대로 유지되지만, 크래시 로그와 사용
이벤트는 전송되므로 그 둘을 분리해서 써야 합니다.

## 아직 결정되지 않은 것
